## Deliberate limits

Research evidence is annual reports and quarterly earnings-call transcripts.
News/search snippets/broker commentary do not become default evidence. Discovery
uses bounded issuer/exchange links and verified directory hints; a separate broad
web-search provider, semantic embeddings, MCP and heavy converters are omitted
under the owner's permission to retain only necessary repetitive tools.

The parser supports explicit statement layouts and INR units, including Mn.
Unrecognized layouts, absent periods, conflicting definitions, mixed-duration
columns, forecasts and unreadable pages remain gaps. Positive quarterly arithmetic
and compatibility/rejection cases are tested; live missing-quarter abstention was
also checked. This implementation does not claim universal extraction, complete
four-quarter promise scoring, every latest issuer release, or error-free external
providers. See PULL_RETRIEVAL_REVIEW.json for the six partially supported queries.

The root workspace verification/audit preserves detailed evidence; this repository
contains the runnable source, build history, operations guide and review ledger.
